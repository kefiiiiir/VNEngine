# tools/

Standalone helpers for working with VNengine projects. One file per tool.

| tool | what it does |
|------|--------------|
| `projectpackager-windows.py` | Build a distributable `<Project>.exe` + `index.html` + `<Project>.pak` from a project folder. Drives auto-py-to-exe headlessly. Needs `pip install auto-py-to-exe`. |
